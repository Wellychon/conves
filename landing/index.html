Contexto compartilhado para times com Claude Code

A equipe inteira,
no mesmo convés.

Convés mantém suas notas em Markdown, o quadro, o grafo e a presença da equipe sincronizados, e entrega isso ao Claude Code por MCP, para que cada sessão comece sabendo o que o time já decidiu.

Ver no GitHub Como funciona

Notas

Sua pasta de Markdown, ou do Obsidian, sincronizada com a nuvem nos dois sentidos e sem sobrescrever ninguém.

Quadro e grafo

Kanban em tempo real, grafo das notas e registro de decisões, tudo no navegador.

Claude Code

Um servidor MCP com poucas ferramentas e comandos de barra, desenhado para gastar poucos tokens.

01Problema

Cada sessão do Claude começa do zero, e o time se repete.

Contexto

O que a equipe decidiu ontem mora em notas, conversas e na cabeça de cada pessoa. A IA não vê nada disso.

Duplicação

Duas pessoas pedem a mesma coisa ao Claude sem saber, porque ninguém vê o que o outro está fazendo.

Decisões

A decisão fica perdida num chat. Meses depois, ninguém lembra do porquê.

Custo

Colar contexto à mão em cada pedido gasta tokens e atenção.

02Produto

As notas ficam onde você já escreve. O resto acompanha.

  1. 1Sincroniza

    O CLI conves sync mantém a pasta local e a nuvem iguais, a cada 5 segundos e ao salvar. Se a mesma nota mudar dos dois lados, a versão da nuvem vai para um arquivo .conflito e nada é sobrescrito.

  2. 2Compartilha

    Postgres com Realtime no Supabase. O quadro, a presença e o que cada pessoa está fazendo aparecem para todos, sem recarregar.

  3. 3Conecta

    O servidor MCP expõe as ferramentas ctx, note, card, log, cal e me, e comandos de barra como /mcp__conves__minhas e /mcp__conves__quadro.

  4. 4Economiza

    Sincronização, arquivamento por tipo e vínculo entre card e nota rodam por hook e por trigger no banco, sem gastar token. O resumo do que mudou só aparece quando mudou.

03Segurança

Texto de outras pessoas é dado, nunca ordem.

Tokens pessoais

Cada pessoa usa o seu, revogável. O banco guarda apenas o hash SHA-256.

Acesso por allowlist

Row Level Security em todas as tabelas. Só entram os e-mails cadastrados como membros.

Conteúdo não confiável

Notas e cards entram no contexto do Claude dentro de um bloco marcado como dado, que o próprio texto não consegue fechar.

Sincronização restrita

Caminhos vindos da nuvem não saem da pasta do vault e não tocam em pastas ocultas como .claude e .git.

Modo privado

Um comando e o que você faz deixa de aparecer para o resto do time.

04Código aberto

Rode no seu projeto Supabase.

# 1. clone e suba o site
git clone https://github.com/Wellychon/conves.git
cd conves/web && npm install && npm run dev

# 2. na sua máquina, sincronize as notas
node cli/conves.mjs sync --watch
